## Como rodar o programa
Com o git instalado, clone o repositório.
```bash
git clone https://github.com/GabrielScatolino/aplicacao-devops.git
```
Entre na pasta.
```bash
cd aplicacao-devops
```
Com o NodeJS + npm instalado, instale os pacotes e dependências.
```bash
npm install
```
Rode a aplicação.
```bash
node src/app.js
```

## Integrantes
Para descobrir quem são os integrantes dessa Avaliação 1. <br>
Rode o programa e faça uma requisição GET no EndPoint /integrantes. <br>

Exemplo utilizando o curl:
```bash

```
